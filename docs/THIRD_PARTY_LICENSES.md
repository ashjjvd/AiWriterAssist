# Third-party software and lexical sources

This repository contains references to third-party libraries, but packages were NOT
installed in the current execution environment, so a dependency-level license
report cannot yet be generated. Run your dependency audit before redistributing.

- **Harper**, Automattic, Apache License 2.0. Source and full license:
  https://github.com/Automattic/harper/blob/master/LICENSE
- **Moby Thesaurus II**, Grady Ward, released to the public domain January 2001.
  Official distribution and documentation: https://www.gutenberg.org/ebooks/3202
  Preserve author notice and Project Gutenberg distribution conditions when using
  Gutenberg-sourced files. The underlying Moby thesaurus content is public domain.
- **Open English WordNet**, Open English WordNet Team, Creative Commons
  Attribution 4.0. https://github.com/globalwordnet/english-wordnet/blob/main/LICENSE.md
  Citation: John P. McCrae, Alexandre Rademaker, Francis Bond, Ewa Rudnicka,
  Christiane Fellbaum (2019), *English WordNet 2019 — An Open-Source WordNet for English*.
- **Princeton WordNet**, Princeton University, original WordNet notice is included
  with Open English WordNet source; preserve it in binary redistributions:
  https://github.com/globalwordnet/english-wordnet/blob/main/WNDB_License.txt

The importer generates a source manifest with release IDs and hashes. A release must
include the complete upstream notices extracted from its source archives, not simply
this abbreviated attribution file.
